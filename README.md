# Fixed STRING protein-feature propagation audit

Code and compact evidence archive for an evaluation study of fixed protein-feature propagation in missense variant pathogenicity prediction. The fixed graph operator has no learned propagation parameters; downstream MLP classifiers are trained. Historical PPI-GCN names are retained in source files for traceability; revised manuscripts use FPP (fixed protein-feature propagation).

## Reproduce the frozen-output checks

The checks require Python, NumPy and pandas. They verify existing threshold counts and complete-case AUC/AP values; they do not train models.

```sh
python revisions/2026-10-23/source/source_data_package_v1/revision_20261008/recompute_checks.py
```

For manuscript and figure generation, see the dated directory README. Source-data checksums inside each `source_data_package_v1` use paths relative to its parent `source/` directory; snapshot checksums use paths relative to the dated directory. Root checksums use repository-relative paths.

## Experimental status and remaining validation

Priority matched-control and repeated homology-fusion runs are complete, with an isolated restored runtime and 48 independently verified classifier fits. Six positive controls exactly reproduce historical recorded metrics. The current [protocol, code and environment specifications](revisions/2026-10-24/reproducibility/code/) and [predictions and verification records](revisions/2026-10-24/reproducibility/outputs/) are published.

The subsequent [experimental addendum](experiments/2026-10-24-external-validation/) evaluates both a variant-disjoint UniProt HUMSAVAR external set and a BioGRID physical-interaction network. The external primary set excludes training/validation labelled proteins and identical sequences; a nested strict subset also excludes original test labelled proteins. STRING representation gains are supported on these external sets, while BioGRID gains over raw features remain uncertain. This is external-source, transductive protein-context evaluation, not independent-patient or prospective clinical validation. BioGRID shares some evidence with STRING. No external clinical-score fusion was evaluated. More specific temporal/predictor-development-disjoint validation, trained GNNs and independent subgroup confirmation remain unperformed.

The latest reporting revision includes the external-source and second-network evidence and uses unified node-wise representation scores, float64 ensembles and a common paired-bootstrap convention. Complete sample memberships and current predictions are published in its compact canonical archive. Historical feature-wise significance is omitted because the old tests ignored within-protein dependence; retained profiles are descriptive. The integrated manuscript includes the external-source and second-network evidence. Its main text remains seven pages including references; detailed evidence is supplementary. Earlier dated manuscripts and the separate experiment record remain unchanged. Fixed propagation results do not establish a performance ceiling for trained graph models. Post-hoc selected subgroup intervals do not account for selection; zero-crossing intervals do not establish equivalence. BioGRID fusion improves on scores alone under the original split, but its incremental benefit over raw-feature fusion remains uncertain. Under the homology split its AUC interval versus scores is only marginally below zero, while its AP interval crosses zero; this does not establish stable harm.

**Provenance clarification:** the retained raw ClinVar backup contains 2026 evaluation dates and cannot be verified as a 31 March 2024 content snapshot. This does not establish the generation date or release of the processed training tables. Those tables are frozen by hashes, but their exact historical release remains unverified. Older dated manuscript snapshots are preserved; the latest integrated manuscript removes the unsupported precise date and identifies the frozen processed inputs without asserting a replacement date.

## Historical code and data

The original archive is retained in `scripts/`, `figures/`, `source_data/` and `manuscript_notes/`. The July-era draft under `manuscript_notes/` is historical; use the dated revision links above for the current text. Historical GraphSAGE-style/GAT-style filenames refer to fixed mean/cosine-weighted operators, not trained GraphSAGE/GAT models. Historical difficulty-matched filenames describe baseline-error stratification, without continuous-score matching.

This is a transparent analysis archive, not a one-command raw-data-to-paper pipeline. Large ClinVar, STRING, CADD and AlphaMissense provider resources, full ESM matrices and model checkpoints are not distributed here. Obtain provider data under the respective terms. The historical scripts may require the original environment and paths; do not run training scripts when only reproducing frozen-output checks.

No additional license or DOI is introduced by this synchronization. Included font license notices are retained. Research use should cite the corresponding data providers and methods as documented in the manuscripts.
