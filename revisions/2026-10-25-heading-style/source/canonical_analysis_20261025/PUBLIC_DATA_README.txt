Canonical frozen-analysis data — 25 October 2026

Purpose and precision
This addendum identifies the exact aggregate variants and split assignments used in the study and provides probabilities sufficient to recompute all 90 current seed-level and 30 ensemble-level full-population metric rows and their paired bootstrap comparisons. No classifier was retrained and no selected checkpoint changed.

Representation-only MLPs were evaluated once per frozen protein node, in actual model-input order, using float32 CPU inference with four threads, batches of 1,024 and evaluation mode. Each protein therefore has exactly one score per fitted model; its variants obtain that same value by lookup. The retained score/fusion models use their unchanged frozen variant-level predictions because clinical-score inputs are variant-specific. All probabilities are converted to float64 BEFORE averaging classifier seeds. Permutation aggregates weight three graphs and three seeds equally. Current AUPRC is non-interpolated average precision as implemented by sklearn.metrics.average_precision_score. Seed summaries use sample standard deviation (ddof=1). Original selected epochs were not reselected under revised reporting arithmetic.

Why representation scores were canonicalized
The earlier variant-batched inference produced tiny floating-point differences for identical protein inputs appearing in different batch positions. These differences can break genuine ties and affect average precision. Current node-wise inference removes those artificial within-protein differences. The maximum absolute probability change is 3.5762786865e-7 against prior internal variant-batched predictions and 4.4703483582e-7 against prior external GPU node predictions, both below the predefined 2e-6 gate. All external populations are remapped from the new canonical node scores. Detailed changes are recorded in canonical_inference_audit.json; the exact old files remain in prior dated archives. Current tables/figures should all use these canonical summaries. They should not mix old float32 ensemble summaries with the present float64 policy.

Files
public/frozen_samples_177213.csv.gz contains all 177,213 distinct VariationIDs, binary label, STRING protein ID, original split, homology split and homology cluster ID. Labels and assignments were joined by VariationID and checked against all six frozen input tables. A precise historical ClinVar content-release date is not independently established; use these identities and hashes to identify the analyzed population.
public/frozen_node_order.csv.gz records the 19,622 actual model node indices.
public/test_predictions__POPULATION__ARM.csv.gz provides each currently evaluated benchmark test row, its VariationID/protein/label, probabilities for seeds 42/43/44, and the float64 ensemble. Individual files distinguish original representation, original fusion and homology fusion. Three separate permutation-graph arms are retained; a pooled 9-fit permutation comparison is calculated from these without pretending the graph samples are nine independent networks.
public/external_membership_and_predictions.csv.gz contains 40,900 unique externally sourced protein substitutions, canonical UniProt accession/AA change, STRING protein ID, label, primary/strict flags, three-seed predictions for raw ESM / STRING FPP / BioGRID FPP and their float64 ensembles. Primary has 10,785 variants; the nested strict subset has 6,934. The full 40,900 includes original training proteins and is descriptive only.
public_manifest.json lists exact hashes, byte lengths, row counts and column names. Every compressed file is under 5 MB. gzip timestamps are fixed to 0, and numeric CSV fields use 17 significant digits; parse with pandas.read_csv(...,float_precision='round_trip') for bit-exact recovery of binary64 values. public_release_verification.json independently checks roundtrip values and recomputes reported metrics directly from these exports.

Uncertainty
All current protein-bootstrap comparisons use 2,000 resamples with np.random.default_rng(20261024), restarted per population. Identical protein resamples are paired across all models in each population. The variant-bootstrap contrast is separate and explicitly ignores within-protein dependence. Intervals condition on the retained fitted models, networks and memberships. They do not include retraining, new-network sampling, all homology dependencies or patient-level uncertainty. Comparisons are exploratory without multiplicity adjustment. Five principal 2,000-resample intervals were independently recomputed through direct sklearn sample_weight calls.

Scientific boundaries
The external set is a separately curated source with explicit overlap exclusions, not an independent patient cohort or prospective validation. Its primary population excludes original train/validation labelled proteins and exact sequences; strict additionally excludes original test labelled proteins and their exact sequences. Both remain within the frozen transductive node universe, and distant homologs are not all excluded. Protein-only scores test transfer of protein context and cannot distinguish substitutions within a protein. No real external CADD/AlphaMissense fusion evaluation is supplied. Primary and strict are nested populations, not two independent replications.
Reproduction and relative paths
All paths in this document are relative to this canonical_analysis_20261025 directory. public_manifest.json file names resolve inside public/. The root CSV and cluster_bootstrap.json files are the current numerical inputs for figures and Tables 11–17. code/ contains scientific analysis and verification code; no SSH controls, process identifiers or private machine logs are included.

A compact read-only check needs only numpy and pandas:
  python code/verify_compact_release.py
It checks all 22 compressed-file hashes, membership and score consistency, and independently recomputes all 90 seed / 30 ensemble metric rows from the public probabilities. Add --ci with scikit-learn installed to recompute all 27 protein-bootstrap comparisons and the separate variant-bootstrap contrast (2,000 repetitions each). Both modes only print a report. They require no model, tensor, provider network or large download. compact_release_verification.json records the locally executed compact point-metric check. The separately executed full verification.json records independent sklearn checks for five complete 2,000-resample intervals and the weighted-kernel tests; public_release_verification.json also checks exact values against original assets.

The server-executed full canonical workflow is preserved in portable public form in code/canonical_analysis.py; code/verify_public_release.py verifies those outputs against original assets. Set PPI_AUDIT_ASSET_ROOT to the frozen input hierarchy represented by assets/ in source_manifest.json. Set PPI_CANONICAL_OUTPUT_ROOT to a NEW output directory when running the full workflow. Large source tensors, checkpoints and original training/score files are deliberately not bundled. These scripts do not retrain models. Original executed source/protocol hashes remain in source_manifest.json; sanitization.json lists the corresponding public-script hashes and path-only portability edits. The weighted bootstrap dependency is code/analyze_external_validation.py. The executed statistical environment used Python 3.10.8, numpy 1.26.4, pandas 2.3.3, scikit-learn 1.7.2, scipy 1.15.3 and torch 2.1.2+cu118; the optional compact CI verifier requires no torch or GPU.

The complete-case supplementary table additionally depends on the original per-variant CADD/AlphaMissense availability mask. That mask and the raw clinical-score columns are not redistributed in these 22 compact files. The current_complete_case_per_run.csv result is supplied, and the original score-table hashes are in source_manifest.json; recreating this specific subset calculation requires those source tables. The public membership/prediction release does not claim to reproduce training or feature generation without the referenced assets.

All 27 paired comparisons retain the same interval sign/zero-crossing classification for both AUC and AP; the directions of their point differences also do not change. This describes numerical stability of these exploratory comparisons, not a multiplicity-adjusted confirmatory test. old_to_canonical_per_seed.json records each fit's metric change.
